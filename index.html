VK → Spotify

Перенесите сохранённую музыку из ВКонтакте в Spotify

1. Подключите Spotify

Нужно разрешение, чтобы создавать плейлисты и добавлять треки.

Для подключения нужно собственное приложение Spotify. Создайте его в Spotify Dashboard, затем в его настройках (Redirect URIs) добавьте адрес ниже — точно как показано, включая порт:

Локально Spotify требует именно 127.0.0.1, а не localhost — проверьте настройки Live Server.

Client ID хранится только у вас в браузере (localStorage) и никуда не отправляется, кроме Spotify.

2. Загрузите архив музыки

Запросите архив своих данных ВКонтакте и загрузите его сюда. Как получить архив →

Перетащите файл архива сюда

или нажмите, чтобы выбрать файл

Разработчики никогда не видят ваши данные — файл архива обрабатывается полностью локально в вашем браузере и никуда не отправляется. Код открыт, можно проверить самим: GitHub.

3. Импорт в Spotify

Выберите хотя бы одно назначение для импорта.

Vk2Spotify — некоммерческий проект с открытым исходным кодом GitHub
